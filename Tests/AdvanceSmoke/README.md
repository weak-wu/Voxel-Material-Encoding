# 提前量与变速回归

从仓库根目录运行：

```powershell
dotnet run --project Tests/AdvanceSmoke/AdvanceSmokeTest.csproj
```

测试调用真实的 `ApplyAdvanceToolOffset` 和 `DirectGeneratePath`，失败返回非零退出码。

规则：A=T0，B=T1，提前量按切入材料选择。从后向前传播所需最大提前量，保证后续各材料连续段的弧长不小于原始长度。每层沿首个有效路径段的反方向补足首段损失，不再按首段长度限制提前量。末段因此可以增长，原始路径拐点和终点保留；首段补偿是实际打印路径的一部分。

例如原始 B20/A10/B20 mm，提前 A3/B6 mm：补偿起点从 x=0 延长到 x=-6，实际切换在 x=14、24，材料段长为 20/10/26 mm。

启用变速后，区域从实际提前切换点开始，长度受实际提前量及下一次实际材料切换限制。前5%的距离由旧材料打印速度线性变到新材料过渡速度，中间90%保持，后5%恢复新材料打印速度。关闭变速仍执行提前切换与首段补偿。

覆盖随机及极短三维材料段、折线拐点、两种切换方向、零提前量、大提前量、首段补偿、多层方向、加速和减速、粗采样下的5%关键点及终点速度恢复。
